# Codex instructions for this MTB & E-Moto game

For **every** task that creates, changes, improves, replaces or integrates a bike, e-moto, other vehicle, vehicle-related 3D model, or branded upgrade part, **read and follow** `.agents/skills/mtb-emoto-bike-models/SKILL.md` before editing code.

Apply the skill to **all existing and future vehicle models**, not just newly added bikes. When asked to improve the full catalogue, audit existing vehicle models, prioritise the weakest ones and implement upgrades in tested batches. Do not claim the full catalogue has been remade unless every model has actually been updated and verified.

Keep MTB pedal/drivetrain rigs separate from footpeg/throttle e-moto rigs. Make upgrades both visually change the installed 3D component and affect riding physics when appropriate. Preserve garage saves across refreshes. Research real reference imagery and manufacturer specs, but only use properly licensed assets.

Inspect the actual repository architecture before work; do not assume Voltline file paths. Preserve existing maps, physics, tricks, controls and other working systems. Test builds, asset loading, garage compatibility, animations and persistence. Maintain clean release notes and version numbers.
